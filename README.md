# Telegram Maze Bot

Телеграм-бот, который публикует сгенерированный лабиринт в канал через мини-приложение. Веб-приложение отрисовывает лабиринт прямо в браузере, а бот отправляет в канал сообщение с кнопкой для открытия мини-аппа.

## Возможности

- Генерация случайного лабиринта с четырьмя выходами и подсвеченным маршрутом между двумя точками.
- Публикация сообщения в канале Telegram c кнопкой мини-приложения.
- Веб-сервер, который отдаёт HTML-страницу лабиринта для Telegram Web App.
- Гибкая настройка размеров лабиринта, размеров ячеек и подписей выходов через переменные окружения или флаги командной строки.

## Конфигурация

Все параметры читаются из переменных окружения (можно использовать файл `.env`, пример — `.env.example`).

| Переменная | Назначение | Значение по умолчанию |
|------------|------------|------------------------|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота | — (обязателен) |
| `TELEGRAM_CHANNEL_ID` | Имя канала (например, `@mychannel`) или числовой идентификатор `-100...` | — (обязателен) |
| `WEBAPP_URL` | Публичный URL, по которому доступно мини-приложение (например, `https://example.com/maze`) | `http://localhost:8080` |
| `HTTP_ADDRESS` | Адрес HTTP-сервера | `:8080` |
| `BOT_COMMAND` | Команда, которую бот ждёт от оператора | `maze` |
| `MAZE_WIDTH` | Ширина лабиринта в ячейках | `40` |
| `MAZE_HEIGHT` | Высота лабиринта в ячейках | `40` |
| `MAZE_CELL_SIZE` | Размер ячейки в пикселях | `20` |
| `MAZE_EXIT_LABELS` | Подписи выходов через запятую | `A,B,C,D` |

## Запуск

1. Установите переменные окружения для токена бота, канала и публичного URL веб-приложения.
2. Запустите HTTP-сервер (отвечает за генерацию и выдачу лабиринта):

```bash
HTTP_ADDRESS=:8080 \
MAZE_WIDTH=40 \
MAZE_HEIGHT=40 \
MAZE_CELL_SIZE=20 \
MAZE_EXIT_LABELS=A,B,C,D \
go run ./cmd/server
```

3. В отдельном процессе запустите бота:

```bash
TELEGRAM_BOT_TOKEN=... \
TELEGRAM_CHANNEL_ID=@your_channel \
WEBAPP_URL=https://your.domain/maze \
go run ./cmd/bot
```

4. Настройте проксирование или публикацию HTTP-сервера наружу (по умолчанию слушает `:8080`).
5. Отправьте боту команду `/maze` (или другую, указанную в `BOT_COMMAND`). Бот опубликует сообщение в канале с кнопкой «Открыть лабиринт».

## Структура проекта

- `cmd/bot` — сервис Telegram-бота.
- `cmd/server` — HTTP-сервис, выдающий мини-приложение.
- `internal/maze` — генератор лабиринта и алгоритм решения.
- `internal/render` — HTML-шаблон и отрисовка лабиринта.
- `internal/server` — HTTP-сервер, который выдаёт мини-приложение.
- `internal/bot` — логика Telegram-бота.

## Разработка

- В приложении используется стандартный логгер `slog`.
- Завершение работы реализовано через общий `context` и обработку сигналов ОС.
- Взаимодействие с Telegram Bot API выполняется напрямую по HTTP, без внешних зависимостей.

Перед публикацией убедитесь, что ваш домен добавлен в настройках бота для разрешённых URL Web App.
